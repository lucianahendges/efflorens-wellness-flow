# Efflorens Wellness Hub

# Prompt para criação de site

Crie um site profissional, moderno, elegante e responsivo para uma clínica de acupuntura por assinatura chamada **Efflorens**.

## Objetivo

O site deve transmitir bem-estar, saúde, acolhimento, equilíbrio e qualidade de vida. O design deve ser minimalista, sofisticado e inspirado na natureza, utilizando tons de verde, branco, bege e detalhes dourados discretos.
